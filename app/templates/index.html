What Happened

The attacker sent 312 requests to the DVWA login page in about 7 minutes. The requests contain SQL injection payloads targeting the users table. Many of the requests returned HTTP 500 errors, which means the injection reached the database. This is a real attack, not a scanner.

What Could Go Wrong

The attacker may be able to read usernames and passwords from the MySQL database, which could then be used to log into the server.

What Should Be Done

Block the source IP address, check the MySQL logs for any successful data extraction, and fix the input validation on the login page.
